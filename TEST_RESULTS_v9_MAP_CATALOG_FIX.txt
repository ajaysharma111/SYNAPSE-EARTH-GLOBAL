SYNAPSE EARTH v9 MAP + GLOBAL CATALOGUE FIX
===========================================

Changes from v8:
- Fixed /api/catalog and /api/regions/install failure: server.py used re.sub/re.fullmatch without importing re.
- /api/world now attempts a one-time download and validation of Natural Earth country boundaries when the file is missing and internet is available. It saves the file under data/ so later map loads work offline.
- Clear fallback instructions are returned if automatic world-boundary installation cannot reach the source.
- Global regional catalogue continues to use Geofabrik's official index; each selected extract is imported into a local offline package.

Validation:
- Python compilation: PASS
- Browser inline JavaScript syntax (Node --check): PASS
- Existing unit tests: 11 passed
- Local server health and /api/regions smoke tests: PASS
- Live /api/world and /api/catalog external network smoke tests: BLOCKED in this build environment (outbound network unavailable); this is not a successful live-download test.

Important usage:
- Start the server from the extracted project root.
- First world map load requires internet unless data/world_countries.geojson is already present.
- If auto-download is blocked, run: python3 scripts/download_world_map.py
- The catalogue is global, but road packages are downloaded per selected Geofabrik extract. Do not install the entire world as one package. Start with the smallest relevant subdivision; large extracts consume substantial disk, memory and processing time.
- Regional packages are separate from the country-outline world map. A world outline does not contain roads, settlements or facilities.
- Existing packages in another project folder are not automatically copied into this release. Preserve and copy your .synapsepack files into the new project's regions/ folder (or use the supported package activation workflow).
- Browser GPS needs localhost or HTTPS.
