SYNAPSE EARTH v8 GLOBAL MAP + LOCATION UPDATE
============================================

Source: user-uploaded SYNAPSE_EARTH_GLOBAL_v7_GPS_FIX project ZIP.

Changes:
- GPS coordinates and accuracy are displayed immediately when browser geolocation succeeds.
- Reverse lookup keeps installed regional settlement lookup as the first/offline option.
- If no installed package matches, the server attempts OpenStreetMap Nominatim reverse geocoding while online. The UI labels this as an online result and does not imply it is cached for offline use.
- Added a worldwide Geofabrik catalogue endpoint (retrieved live while online).
- Added an in-app regional package installer that accepts only official HTTPS download.geofabrik.de .osm.pbf URLs, applies the selected catalogue bounding box, imports the region, and activates it.
- Installer limits individual PBF downloads to 3 GB. Prefer small country subdivisions/regions.
- Existing installed packages remain available offline.

Important:
- Nominatim online reverse geocoding is subject to the public service's usage policy and availability. It is not an offline geocoder.
- Geofabrik catalogue contents and extract sizes change over time. Large extracts can take a long time and require substantial disk space.
- The OSM importer still imports selected highway classes plus settlement/facility nodes; it does not create a certified navigation or emergency dispatch system.
- No live hazard feed, verified facility operations, or guaranteed safe evacuation route is provided.
