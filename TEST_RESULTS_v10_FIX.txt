SYNAPSE EARTH v10 FIX VALIDATION
===============================

- Python compileall: PASS
- JavaScript syntax (node --check): PASS
- Unit tests: 11 passed
- Changes:
  * Global catalogue options now use stable region IDs instead of array indexes.
  * Catalogue selection and installation errors are shown explicitly.
  * GPS detection fills the route planner's start coordinate automatically.
  * Guest, sign-in and modal-close controls are bound immediately, independently
    of later map initialization.
  * Existing API-based OSM installation and offline package storage retained.

Not tested in this build environment:
- Live Geofabrik catalogue availability and large regional PBF downloads.
- Physical browser GPS permission/location.
- End-to-end account signup/login in a real browser.

Important:
- A regional package is not installed merely by loading the world boundaries.
  Use Browse worldwide maps, select a small region, and click Install selected.
- The app needs internet while downloading/importing a regional OSM extract.
  After installation, that package is stored locally and can be used offline.
