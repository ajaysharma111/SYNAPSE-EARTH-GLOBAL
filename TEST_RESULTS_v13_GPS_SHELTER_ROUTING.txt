SYNAPSE EARTH v13 — GPS-FIRST SHELTER ROUTING

Changes:
- Added automatic nearby shelter / emergency assembly-point discovery from device GPS.
- Added candidate road-route calculation to explicitly tagged shelter records in installed regional packages.
- Added map overlays for GPS position and candidate shelter destinations.
- Added destination selection that draws the road path and displays distance plus a clearly labelled rough walking-time estimate.
- Extended new OSM imports to preserve shelter, amenity and healthcare tags.
- Kept the worldwide Geofabrik catalogue: available extracts can be searched and installed country/subregion-wise.

Validation:
- Python source compilation passed.
- JavaScript syntax check passed.
- Existing unit tests: 11 passed.

Important limitations:
- The worldwide catalogue is not a preinstalled global road graph. Each regional extract must be downloaded and installed.
- Existing packages created by earlier importer versions may not contain all shelter tags; re-import the region with v13 to preserve the expanded tags.
- OSM shelter/assembly point records can be incomplete or outdated. This application cannot certify safety, availability or hazard exposure.
- Route is a candidate path through the imported road graph; closures, turn restrictions, terrain, flood/fire exposure and live traffic are not fully modelled.
- Some mapped shelters are OSM ways/relations rather than nodes; this importer currently discovers facility nodes only.
